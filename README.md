# 🩺 Diabetes Clinical Chatbot

Evidence-based clinical decision support system for diabetes mellitus using USPSTF guidelines.

## 🚀 Features

- **100% Local** - No API keys required, runs entirely on your machine
- **Lightweight** - Uses small models (~400MB total)
- **RAG Pipeline** - Retrieval-Augmented Generation for accurate answers
- **Citations** - Every answer includes source document and page number
- **Streamlit UI** - Simple and intuitive web interface
- **FastAPI Backend** - REST API for integration

## 📦 Models Used

| Model | Size | Purpose |
|-------|------|---------|
| `all-MiniLM-L6-v2` | 80MB | Text embeddings for semantic search |
| `google/flan-t5-small` | 300MB | Text generation for answers |
